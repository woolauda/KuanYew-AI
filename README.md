# KuanYew AI 本地预览

使用 Node.js 24 或更新版本，在本目录运行 `npm start`，然后打开终端显示的 `http://127.0.0.1:4173/`。无需安装依赖。

- 首页显示 AI 工具目录、官方来源的资讯、作品分类和入口说明。资讯会在访问时尝试读取 OpenAI、Google DeepMind、Hugging Face 的 RSS，每 30 分钟缓存一次；读取失败时会显示 2026 年 9 月 30 日核对的文章。
- `community.html` 是话题与回复页面。内容保存到本机 `.data/community.sqlite`，重启服务后仍然存在。
- 这是本地预览包。若要让其他访客从不同设备共同发帖，需要把后端与数据库部署到可访问的服务器。直接双击 `dist/index.html` 只能查看静态页面，不能发帖。

工具卡片的图标优先从对应产品官网下载；如果访问失败，页面会尝试后备来源，再显示文字标识。
